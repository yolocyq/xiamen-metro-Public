总公式

Pi(d) = Bline · (wi / Σw) · gcal(d, typei) · gweather(d) · novelty(d) · fare hourlyi(h) = Pi(d) · φ(h ; typei, dayclass) / Σh φ wi = T(typei) + 0.22·ntransfer + 0.16·isTerminal + 0.11·catchmenti fare = 0.86（固定，把免费试乘口径折算为正式收费运营口径）
所有客流数值在界面上一律四舍五入到千位。理由很实际：模型本身的误差远大于十位、百位， 保留到个位只会给出虚假的精确感。
